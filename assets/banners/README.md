# Home banner album (app)
Weekly (every Thursday 14:00 Iraq time): 5 new banners = 2 QTK + 1 DLG + 1 DRS + 1 KLV, designed by Claude (Opus 5.5), reviewed by the CEO as an HTML preview, then added here and listed in banners.js.
The app shows 5 banners per day (2 QTK, 1 DLG, 1 DRS, 1 KLV) and advances one step per family per day (Iraq time).
Static 1320x480 copies of each banner (4 languages) are also saved in each product's Assets folder in Drive (beside Images).
Tools: tools/banners/add_banner_batch.py (append an approved batch to app + website), tools/banners/test_banners.js (checks), tools/banners/render_finals.py (static copies). Then tools/make_review_bypass.py.
Batches: 1 = 2026-10-01 (5), 2 = 2026-10-08 (5).
